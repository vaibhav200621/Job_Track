# JobTrack — Placement Management System

JobTrack is a web-based placement management system designed to help students organize and track their placement activities in one place.

## 🎯 Objective
To simplify placement preparation and job application tracking for students.

## 🚀 Planned Features
- Student registration and login
- Student profile management
- Job and internship application tracking
- Placement-related updates

## 🛠️ Tech Stack
- Frontend: React, Vite
- Backend: Node.js, Express.js
- Database: MongoDB

## 📌 Project Status
Currently under development. Features will be implemented step by step.
